# 论文便捷阅读skill

把用户指定的论文做成一篇可直接用浏览器打开的 UTF-8 HTML。默认按 Golsefatan 阅读样张的编排：英文原文列稍宽，旁列中文意译与中文批注；左侧双语章节目录、正文前的技术路线、文末的论证总览。每篇是独立文件，打开时无需联网、启动服务或安装字体。

## 获取和精读

1. 接受本地 PDF、附件、全文网页、DOI、arXiv 或可辨识题名。优先使用用户提供的文件与权威原件，核对题名、作者、出版/在线日期、期刊和 DOI。记录本次实读的版本、页段与附件。若正式 PDF 未取得，能读取完整期刊 HTML 或作者稿时继续，显著标出“待补正式 PDF”、DOI 和各项缺件。只有摘要时告知全文获取状态，提供合法来源；不将摘要扩写为全文。用户补入 PDF 后，按编号替换已核验的缺项并保留旧版。用户材料留在本地。确认取得与使用正文、原图的权限，按许可保留必要署名和版本说明。
2. 实际阅读正文、附录及与方法或结论有关且可取得的补充材料。先按印刷章号、子节、段落、图表和公式建立清单；图注与正文交叉引用分别识别。双栏原页先核对阅读顺序，扫描稿先 OCR 并目核。保留无标题段落和图表题注；编辑添加的标题或阅读序号应可辨识。核查参考文献、声明等文后材料的覆盖状态，无法核对的段落单独标明。
3. 英文论文按原文与原段落保留。遇中文原稿，用“中文原文／英文译文”准确标识来源。仅请求节选时，以实际页段为限并在页面标明节选边界。中文用学术意译，句组映射允许一对多，保留因果限定、单位、比较基准、样本量与不确定性。每段的中文批注解释在本段出现的对象、证据或推理：问题如何引出、量如何测得或反演、方程怎样连到观测、哪些对照支持主张、哪种替代解释仍成立。关键结论给出可复核的图/表/式或页段；区分原文结论、独立判断与设想。
4. 选最相关的 1–3 项作者/团队既往研究，核对作者与机构身份，区分已读全文和仅核书目。比较研究问题、模型、实验或验证上的变化。期刊指标分别注明中科院分区、新锐分区、JIF、年发文量的年份、口径及来源；缺值明确标注。预印本注明版本和评审状态。工程启发以该论文的实际工况为准。

## 排版与交付

- 使用 [读本数据与原件处理说明](references/reader-data.md) 准备临时材料；由助手完成提取、双语逐句对齐、逐段解读和组装。用户提供的单篇额外要求优先。目录要与正文的英中标题和原有编号对上；单独绘制这篇论文的技术路线，写出具体输入、方法、对照、输出及彼此关系。
- 把图片、图例、分面、完整表头/表注与相关段落放在一起。长表保持可横向阅读或提供多页原表。公式用原生 MathML 编排，保留可复制源码。缺图而有图注时逐项标出，勿以其他文章或数据仓库的同名图片代替。
- 在工作目录中运行 `python "<本 skill 目录>/scripts/render_reader.py" "<精读材料.json>" "<输出目录>/<论文简称>_三栏精读.html"`。镜像/周报返回链接仅在用户要求或既有周报场景配置；独立调用可保存到用户指定目录或当前工作目录。输出重名时自动添加版本后缀；以脚本实际返回的文件名为准。
- 写入后用 `python "<本 skill 目录>/scripts/check_reader.py" "<实际输出.html>"` 回读。把检查输出的段落、图表、公式（含待补项）和目录与独立的原件清单逐项核对；核对每一对句组语义及高亮范围。可以运行 `node "<本 skill 目录>/scripts/check_browser.cjs" "<实际输出.html>"`，或在浏览器离线检查桌面、手机、双向悬停/键盘/触屏联动、目录跳转与返回、图表放大、长公式适宽与原字号末端。原件复杂的图表与长公式回看实际显示。若无法启动浏览器，说明只做了静态核验。
- 文末用问题、主张、证据、回应和结论说明论证骨架，给出一句话主张及最强/最弱证据。最终回复提供成品链接和实际缺件。读本规则或版式后续可更新于同一个 skill；是否重新生成旧读本按用户指定范围执行。
