# 场景与执行契约

0.2 新增自适应 Plan、源证据、跨表示选择、结构补丁及定向修复，详见 [自适应契约](adaptive-reconstruction.md)。以下 0.1 Scene 与操作继续保持兼容；其中关于 0.1 补丁的限制不代表新增结构补丁也受相同限制。

## 权威输入与产物

Plan 是宿主对原图的可执行重建决定；Scene 是已解析的最终几何。SVG、PNG、对象 Manifest、QA 和回执从 Scene 派生。对象 ID 由宿主/计划明确给定，不按名称重算。trace 子路径的 ID 在同一源区域及分割参数内按组件稳定排序；改变分割阈值或对象拆分时不承诺自动身份匹配。

源坐标按 `source.region` 映射到画布，首版一像素对应一个场景单位。Scene 的 `transform=[a,b,c,d,e,f]` 映射为 `x'=a*x+c*y+e; y'=b*x+d*y+f`，嵌套变换先局部再父级。像素操作补偿父级矩阵，以免源坐标被重复应用。兄弟节点顺序决定绘制顺序。

## 操作

- `construct`：消费显式 rect/ellipse/path/text/group/connector；几何来自宿主，保留 evidence。
- `trace_region`：实际读取源图区域，分割颜色/遮罩，保留多环复合路径，拟合曲线，渲染自审和最多三轮修正。
- `fit_stroke`：从单连通细直线恢复开放中心线与估计描边；有弯曲/分支则拒绝强拟合。

每步的 `depends_on` 必须已经完成，步骤 ID 不得重复。结果须通过 Schema 和语义验证，包括有限值、对象/资源 ID、父子循环、连接依赖、路径语法、孔洞可表达性和字体字符覆盖。未支持的样式或资源显式报错。

## 补丁

```json
{
  "base_revision": 0,
  "operations": [
    {"id": "nucleolus", "set": {"style": {"fill": "#325daf"}}}
  ]
}
```

0.1 支持合并更新 geometry/style/semantic、替换 transform、更新 visible。ID 和 parent 不可通过此补丁改写；拆分/合并、重挂父节点等完整生命周期尚未实现。连接线由端点对象和锚点派生，非依赖对象不会被自动重排。

先在拷贝中验证补丁，再生成临时产物；revision 相符才切换工程目录，失败回滚。并发写入使用独立锁文件，崩溃遗留锁需人工确认进程结束后处理。它是目录级暂存与回滚，不承诺断电后的数据库事务恢复。

## 局部导出

选择节点的后代形成内容闭包，祖先仅保留必要外壳以继承变换、样式和组透明度，不带入未选兄弟。引用渐变随输出保留，viewBox 使用世界边界并包含描边/箭头余量。选中的连接线冻结为独立 path，避免导出后仍依赖未选端点对象。

## 审计与状态

- 执行 success 与质量 needs_review 独立。
- 自动几何审计记录每轮候选、指标、拒绝原因、修正轮数和最终策略。
- 源图比较图及全局 MAE 仅描述差异；未简化轮廓只是局部几何基线，不是科学真值。
- 宿主按照 SKILL.md 和通用绘图规范检查结构、线条、填色、文字及局部编辑任务。
- 修改后旧像素自审不再绑定当前几何，标为 stale_after_edit。
- `receipt.json` 绑定产物哈希，检测工程文件被外部改写；没有对任意外部 SVG 的无损反向导入。

## 当前支持矩阵

本机 Windows / Anaconda / Python 3.12 / CPU 已验证；渲染无 GUI，基础测试在 Python 网络调用被禁用时通过。Linux、WSL、GPU 及 OS 层禁网容器尚未实测。渲染固定本机字体文件并记录哈希；系统字体不打包，不能承诺跨字体像素完全一致。
