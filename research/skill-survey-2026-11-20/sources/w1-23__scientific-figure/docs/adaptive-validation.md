## 实施中发现并修复

1. NumPy 拓扑计数不能 JSON 序列化：在公共拓扑函数转换成 Python int。
2. 相邻颜色各自轮廓出现透明裂缝：改为保留真实孔洞的连续主体底色，上层补内部颜色结构。
3. 抗锯齿窄色带被当作独立材料分区：保留所有误差诊断，仅把存在可分辨内部的颜色区域作为自动完整性约束；宿主指定细部另做实际编辑检查，不忽略。
4. 透明孔洞与白色绘制孔洞在白底源图下被误判：比较两侧采用同一源图合成语义；alpha 另行记录。
5. 组名可以假冒独立部件：增加实际隐藏编辑的区域效果检查，错误大组会被拒绝；颜色组继承填色，单独改色确实改变可见结果。
6. 无改善也可能增加 revision：按请求的故障分别检查收益，未改善保持原 Scene。
7. 分析/profile 变化未使审计过期：同时校验分析、profile、几何及 revision 摘要。
