# 学术人类化写作与研究文案

## 目标

让文字像一个真正理解问题、对证据负责、知道自己要告诉读者什么的作者写出来。人类化不是口语化、夸张化或故意加入个人腔调，也不是把所有限定词删掉；它要求句子有明确的主语和动作，段落有推进，语气与证据匹配，读者能感到作者在做判断，而不是在执行模板。

人类化改写不能解决主线不清的问题。若文档读完仍不知道要说明什么，先按[文档清晰度与信息密度](文档清晰度与信息密度.md)重组目的、标题和逻辑台阶，再做句子润色。

写作时先确认当前文体。论文正文、实验记录、汇报标题、项目 README 和对外文案可以共享事实，但不使用同一套句式。

| 文体 | 首要任务 | 默认语气 |
| --- | --- | --- |
| 论文正文 | 提出问题、解释机制、陈述发现 | 坚定、具体、克制 |
| 实验记录 | 还原发生了什么并保留边界 | 直接、可追溯、允许不完整 |
| 汇报标题与页面文案 | 让读者迅速抓住一个判断 | 短、具体、有动作 |
| 项目 README | 帮助下一次接续和使用 | 清楚、可执行、少套话 |
| 摘要与结论 | 留下问题、贡献、结果和认识 | 集中、有取舍、有记忆点 |

## 写作前先确定一句主判断

每段先回答：读者读完后应该相信什么、理解什么或采取什么动作。段首通常给出主判断，随后解释原因、条件和证据；如果段落承担的是转折、定义或铺垫，直接说明它的功能，不用空泛的过渡句填充。

每段围绕一个主要判断展开，按需要连接背景、机制、证据与推论，避免在同一段堆放互不相关的信息或反复自我辩护。

## 去除防御性写作

防御性写作是把假想审稿人的质疑提前塞进每一句话，使作者的判断被大量“可能、在一定程度上、需要指出、不能排除、并不意味着、仍有待进一步”等表达包围。处理方式不是机械删除这些词，而是把真正有用的条件放到正确的位置：

- 结果段直接报告观察到的对象、比较、条件和数值；
- 机制段说明这是解释、推断还是预测；
- 讨论段集中处理适用范围、失败条件和未解问题；
- 只有会改变当前句子含义的限定才留在句内；
- 不为每个结论追加“这并不代表……”，除非读者确实可能据此得到错误理解；
- 不把真实失败写成自我否定，也不把局部不足扩展成整项工作的价值判断；
- 不在正文中连续回答尚未出现的审稿意见；有实质质疑时，用证据、分析或明确的范围回应。

直接、准确的句子优先于安全但空泛的句子。例如：

- “在一定程度上表明该方法可能有助于提升恢复能力” → “在固定干预强度和相同模型调用预算下，该方法将任务成功率从 A 提高到 B。”
- “需要指出的是，本实验仍存在一些局限” → “该实验只覆盖仿真中的单次干预；持续外力和真实机器人执行尚未测试。”
- “本研究不仅……而且……” → 拆成两个有明确主语和证据的句子，除非两项内容确实构成一个不可分的贡献。

不能用改写掩盖证据缺口。没有数字、对照或来源时，直接标记“尚未验证”“待分析”或“未运行”，不要用更委婉的形容词替代事实。

## 让文字像人在表达

- 使用具体主语和动作动词，少用没有动作的抽象名词串；
- 交替使用短句和展开句，让节奏跟随推理变化；
- 让段落之间有真实的因果、转折或递进关系，不用同一组连接词机械起段；
- 不让每段都以“本研究”“此外”“因此”“值得注意的是”开头；
- 不把每段写成“三点一组”的整齐模板，除非内容本身确实是并列关系；
- 保留作者判断和具体取舍，不把所有句子磨成无来源的中性摘要；
- 术语保持稳定，但同一术语不需要为了“避免重复”强行换同义词；
- 学术表达可以有节奏和个性，但不能使用戏剧化、广告化或口语化表演掩盖内容空缺。

标题和汇报文案应帮助读者抓住具体对象和研究判断，少写空泛名词堆叠。例如讨论失效来源时可用“误差主要来自预测还是执行”，讨论贡献归因时可用“同等预算下，新增模块是否仍有收益”。标题中的结论须有实际证据，正式论文章节同时遵循目标场所的结构要求。

## 人类化改写的要点

1. **先读上下文。** 阅读段落前后的论证、图表、实验记录和目标读者，不脱离上下文逐句替换。
2. **标出主判断。** 区分事实、解释、预测、计划和局限；确认段落要留下的一个主要认识。
3. **清理模板层。** 删除空泛开场、过程播报、重复总结、假想答辩和无信息自评。
4. **重建句子。** 用具体主语、动作、条件和结果重写；必要时调整句子顺序和段落结构，而不只做同义词替换。
5. **恢复作者声音。** 参考用户确认过的文字，保持术语、句子节奏、判断方式和叙述视角；不把所有文本改成同一种“标准学术腔”。
6. **保真复核。** 对比数字、分母、单位、正负方向、否定、公式、引用、标签、状态词、实验范围和证据强度；发现变化时回退或明确说明。
7. **成稿交付。** 正文只保留读者需要的内容。改写说明、证据缺口和待核对事项另列，不把编辑过程混入文稿。

根据任务选择起草、结构重组或局部改写。已有文字先定位主要问题；委托写作或成稿时，直接完成所需起草与修订。缺少关键事实时查证或保留明确的待补项，不虚构内容，也不把流程名称当作必须逐项执行的模式。

## 交付前检查

- 每段是否有明确判断，而不是只有背景或过程；
- 是否把必要限定放在它真正影响的句子附近；
- 是否存在连续的自我否定、假想答辩或通用免责声明；
- 是否有句子只是因为“听起来学术”而存在；
- 标题是否包含对象、动作、变化或问题，而不是只有抽象名词；
- 句子节奏是否过于整齐，是否反复使用相同开头和连接词；
- 改写是否保持数字、来源、术语、状态和证据边界；
- 读者能否在不阅读协作过程的情况下理解结论。
