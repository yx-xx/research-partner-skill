# 选题与面向决策的文献调研

## 生成有区别的研究机会

按当前问题选择少数互补视角，不跑固定数量的头脑风暴，也不要求用户先完成访谈：

| 起点 | 具体做法 | 应得到的研究增量 |
| --- | --- | --- |
| 真实失败或反常现象 | 检查何时失效、为什么失效、现有评估是否掩盖它 | 可解释的边界、机制或修复 |
| 被默认的权衡 | 检查效率/性能、泛化/专用、可靠性/能力的冲突是否真实 | 改变权衡或解释不可避免的边界 |
| 条件改变 | 找旧方案依赖的算力、数据、传感或理论假设，核实现在改变了什么 | 原先不可行的能力或新的判断 |
| 抽象层次变化 | 将具体问题提升为一般原理，或在关键现实条件下检验一般原理 | 更广的洞见或有价值的失效分析 |
| 跨领域迁移 | 用无领域术语描述结构，核对另一领域的方法假设能否映射 | 可推导、可检验的机制，不止术语类比 |
| 拆解与简化 | 隔离复杂系统的真正瓶颈，认真调好最小方案 | 揭示必要机制、消除无用复杂度 |

从新技术出发也可以，但必须找到其改变的具体问题；从已有设备出发也可以，但不能把方便实现当成问题重要性。利用 [项目状态中的已有积累](长期接续与多项目.md) 判断哪些方向更容易形成有意义的区别、减少重新学习与搭建的成本，同时保留新路线；不把复用旧资产作为选题前提。候选应体现不同研究假设，不能只是同一想法的三个名字。

每个进入比较的候选说明：问题及影响、最近竞争工作、核心假设、最强反例、最小区分性验证、资源依赖、可能的论文类型，以及失败后能否产生有价值的发现。按 [顶刊顶会标准](顶刊顶会标准.md) 预判“成功后能贡献什么”，比较重要性、区别证据、验证成本、竞争风险和用户投入，推荐主线，不给虚构综合分。已有方案解决大部分问题时，从尚未解决且有价值的条件出发，按 [实验与分析](实验与分析.md) 构造和验证候选解法；单纯增加模块不能替代这一步。保留真正可替代的备选，证据足够后转入验证。

## 检索服务一个明确决定

先说明本次检索要决定什么：排除明显撞车、确定最强基线、检验机制，还是支撑最终新颖性表述。围绕“问题/任务—机制—假设—评价”组合查询：包括常用同义词、同问题的不同命名、负面表述和相邻领域；沿最接近论文的参考文献与后续引用追踪。既看近期预印本，也追溯基础方法，不能只读最新热点。

机器人/机器学习通常从 arXiv、官方会议/期刊论文页、OpenReview、作者项目/代码与综合索引选择合适来源；无需同时调用所有数据库。实际调用 API 时可使用 `paper-lookup` 的对应参考和解析器；没有该 skill 时使用现有检索工具与权威页面，保留同等来源记录。

检索或下载成功要检查正文内容：HTTP 200 不等于有效论文，元数据不等于全文，下载全文不等于已经阅读。核对标题、作者、标识、版本、发表状态与返回内容；预印本与正式版去重并记录关系。API 空返回、限流、解析错误、不可访问和确无匹配分开记录。失败时尝试合适的替代入口，不把访问失败写成文献空白。

保存足以复查的日期、数据库/页面、查询与范围、筛选规则、原始响应或来源链接、去重方式和访问缺口。对会支撑关键判断的原文保存实际读取段落/章节或表图位置；页码未经核对就用章节定位。复用缓存前检查版本与时效；定稿前补查期间新增的最近工作。

## 文献对照要能改变方案

优先深入阅读最接近的方法、最强基线和可能否定主线的工作，不以论文数量或逐篇摘要代替综合判断。可在已有文献表使用以下字段：

| 文献与版本/标识 | 阅读范围与定位 | 问题、假设、方法 | 结果及边界 | 与本研究的关系 | 会改变的设计或主张 |
| --- | --- | --- | --- | --- | --- |
| 可核验来源、日期、发表状态 | 摘要/相关章节/全文；具体位置 | 实际提供什么能力、依赖什么信息 | 数据、预算、任务、指标；未知保留 | 已解决/部分重叠/互补/反证 | 需复现、需比较、要收窄或可借用 |

来源存在性与句子支持性分别核验。不能从摘要推断其没有某消融；不能从仓库 README 推定论文报告过某结果。无法获取最近工作关键部分时，创新性保留暂定并明确该缺口。

综合时回答：哪些结论跨条件一致，哪些冲突源于数据、设定或指标；真正尚未解决的是什么；哪些看似空白只是名称不同、任务不重要或已经被简单方法覆盖。对每个主要缺口指出来源证据和可检验后果。普通选题调研不冒充系统综述；用户明确要求系统综述/元分析时另制定检索、筛选、偏倚与合成协议。

## 反向查新与停止条件

对主推方向主动查找：

- 已有工作是否在等价设定下实现同一贡献？
- 标准基线加简单校准、更多合理调参或充分资源是否已足够？
- 问题是否只在不现实的条件、错误指标或人为削弱的基线上出现？
- 所谓新机制是否其实是额外数据、计算预算、信息访问或测量误差？

最危险的反对意见转成 [实验与分析](实验与分析.md) 中的判别检验。反对证据成立就修订、转向或停止；记录重启条件，避免下次重做同一方向。

当主要术语路线、最近竞争者与关键引用链已覆盖，追加搜索不再改变当前选择时，报告范围和剩余未知并进入验证。若关键区别仍不清楚，则只做可逆探索，不能以“查了很多”支撑完整创新主张。交付主推方案、必要备选、证据与最便宜的下一验证；使用“在所查范围尚未发现”，不声称普遍不存在或已证明首创。
