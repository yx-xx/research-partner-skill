# 顶刊顶会的贡献与完成标准

## 先确定读者与贡献类型

顶刊顶会没有统一的实验数、涨点幅度或写作模板。先判断主要贡献是理论、方法、系统、数据/基准还是实证发现，再确定目标读者为什么需要它。用户已指定场所时按其要求工作；没有指定时给出有理由的暂定主目标与备选，继续通用工作，不因尚未选刊而停止查新或验证。

投入主要实验资源前，以及定稿前，核对当前目标的官方范围、论文类型/track、评审标准和作者指南。记录来源、适用年份与访问日期；往年页面只能作历史参考。选读近期同类论文，提取贡献大小、关键比较、证据组织与呈现方式；这些是校准样例，不能当作最低实验数量或官方录用规则。不凭会议名声推定论文契合度。

目标画像可放在已有提案或状态中：

| 项目 | 记录内容 |
| --- | --- |
| 主目标与备选 | 场所、track、贡献类型；用户确认或助手暂定 |
| 目标读者的判断 | 什么新知识/能力值得关注；最可能的拒稿理由 |
| 官方依据与同类样例 | URL、日期、实际读过的内容、对本稿的启示 |
| 必要证据 | 按主张列出必须补齐的理论、对照、分析或实证 |
| 执行约束 | 篇幅、截止时间与时区、匿名、附件、代码/数据/AI 政策 |

无法联网时先作贡献类型层面的判断，具体场所规则保留待核验，不宣称“已符合顶会标准”。

## 判断贡献的实质

| 贡献类型 | 需要说清的增量 | 优先挑战的问题 |
| --- | --- | --- |
| 理论 | 新结论、条件放宽、界的改进或不可能性；对已有结论的实际改变 | 是否只是已知定理改写；假设是否使结论失去意义；证明是否完整 |
| 方法 | 可解释的新机制或有价值的能力、效率与可靠性改进 | 同预算简单方案是否足够；收益是否来自额外数据、算力或调参 |
| 系统 | 过去无法可靠实现的能力及可迁移的系统洞见 | 是否只是集成演示；关键设计是否必要；端到端成本与失效是否透明 |
| 数据/基准 | 被证明重要的新覆盖、有效测量或可靠比较能力 | 任务是否真实；指标是否有效；污染、泄漏、许可与使用门槛是否处理 |
| 实证/负结果 | 稳定、可复验且会改变领域判断的发现或边界 | 是否是实现缺陷或偶然性；竞争解释是否排查；范围是否足够有意义 |

实质贡献可以简单，也可以是大幅工程改进；关键是重要性、区别和证据。反之，理论、实机、更多任务或更大模型都不是所有稿件的必选装饰。

用一句有边界的话表达拟贡献：“在条件 C 下，现有路线 A 的限制是 X；我们提出/发现 Y，通过证据 E 支持结论 Z。”研究前将 E/Z 写为待验证；研究后替换为真实范围。进一步回答：去掉方法名称和术语后还剩什么洞见？已有工作加简单改动为什么不能解决？哪项证据会推翻主张？

## 主要投入前预判成功后的贡献

在选择主线、扩大投入或核心设想改变时，依据已读最近工作与目标画像，先做一个明确标为假设的判断：如果计划中的核心结果成立，论文实际能增加什么？在已有提案或状态中简述：

- **新增价值**：谁会因此改变方法选择、理论认识、评价方式或实际能力？对应哪项尚未被满足的需要？
- **最近对手**：最接近工作与同信息、同预算简单方案已经做到哪里；预想增量是否超出常规适配或已知结论？
- **决定性证据**：哪项结果能把新贡献与这些对手区分；当前最容易得到的结果是否真的承担这个判断？
- **完成路径**：获得该证据需要哪些关键依赖，现有资源能否覆盖，用户须承担多少工作？

据此推荐直接验证、先补一个关键未知，或重构问题/方法。若预想成功仍不足以支撑目标贡献，先寻找更有意义且可验证的增量，再投入大批训练或采集。若只是来源、机制或可行性尚不清楚，安排有预算的探索，不把“未知”判成“没有价值”。用户已确定范围时在范围内改进；需要改变目标的取舍按已有约定交流。

该判断用于比较投入价值，不预测录用、不填写预期结果数字，也不在每个小步骤重复做整套评估。新证据推翻预判时及时修订。

## 三项判断分开记录

| 判断 | 达成所需依据 | 未达成时的行动 |
| --- | --- | --- |
| 研究有效性 | 测量与设计适合主张；推导正确；比较公平；不确定性、反例与来源清楚 | 修复设计/实现、补证据或收窄主张 |
| 目标场所竞争力 | 问题重要；相对最近工作有实质增量；证据深度与目标读者匹配 | 增强关键贡献、重定位或建议其他场所；不以润色替代 |
| 提交完整性 | 完整稿件、图表、引用、附件与当前格式要求一致；文件可读/可编译 | 完成制作和核对；不得以格式合格代替科学判断 |

每项用“依据支持 / 尚缺什么 / 无法核验”描述，不算综合分或录用概率。继续、调整或停止是有依据的研究建议；是否正式更换目标或提交，遵循用户选择及现有授权。

## 随阶段应用，避免过早做全套审计

- **选题投入前**：问题有价值；最近工作与简单替代尚未否定它；关键验证在资源内可做。查新未完成则只允许暂定判断与可逆探索。
- **扩大实验前**：测量和基线可靠；关键风险有实际证据；下一批实验明确服务哪项主张。小样本正结果只决定值得继续，不直接宣告有效。
- **定稿前**：必要主张均有支持或已删除/收窄；主要反对意见有证据处置；正文与结果一致。尚有致命缺口则不能标为“可投稿完成”。

截止日期决定工作排序和范围取舍，不决定结果或证据标准。优先保护主线与关键验证，砍掉无关扩展；若无法形成完整贡献，明确建议延期或调整目标，不反复生成更乐观的故事。
